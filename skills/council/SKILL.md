# council

Several independent reviewers, loop to agreement.

- Send the change to 2–3 models from different providers. Independence is the point — don't let them see each other first.
- Collect findings; keep only what's reproducible (`interrogate` discipline).
- Fix, then re-review. Loop until they converge with nothing substantive left.
- Reserve for high-stakes diffs — it's expensive. Most changes only need `interrogate`.
