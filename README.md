# skill-stack

Personal, **tech-agnostic** agent-skill library. Platform-agnostic (Claude Code · Codex · Cursor · ChatGPT). Modernised from [tstack](https://github.com/t3dotgg/tstack) (Theo) and [pstack](https://github.com/cursor/plugins/tree/main/pstack) (poteto).

## Ethos: move fast · break things · try new things

Built for capable models. No ask-first, no plan rituals, no baked-in stack.

- **Full send** — autonomy to merge.
- **Fearless parallelism** — swarm / arena / interrogate.
- **Prove it works** — runtime evidence.
- **Never block** — proceed, verify, present.

The tech stack is never assumed. It's chosen per project, at `kickoff`, by what the project needs. Every skill holds regardless of stack.
